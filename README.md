# Żużel — kreski

Przeglądarkowa gra żużlowa na kratce, inspirowana klasycznymi „kreskami”
(gra na kartce w kratkę oraz programy typu *Kreski / Żużel 2001*).

Zawodnicy jeżdżą po siatce, stawiając kreski. Długość kreski to prędkość —
w każdej turze można ją zmienić najwyżej o jedną kratkę w każdej osi.
Za szybko na łuk = banda i upadek.
